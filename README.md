# 东方夜雀食堂客人攻略查询表

## 目标与范围

为《东方夜雀食堂 - Touhou Mystia's Izakaya》整理一份可查询的 Excel 攻略表，
核心列顺序为：客人名字 → 出没/金钱 → 喜好/厌恶 → 前期菜谱 → 后期菜谱 → 加料推荐；
同时补充符卡、羁绊解锁、酒水推荐、普通客人、菜谱/食材/酒水速查和数据来源说明。

范围：官方本体 + DLC1-DLC5 + v4.4.0 联动内容（秦心、四个情绪面具、妖精服）。
不包含 MetaMystia 联机 Mod 示例 ResourceEx 包（数据内标记为 DLC9，如芙兰朵露、八意永琳、神绮、秋姐妹等）。

  - 营业图鉴·人物页签：稀有/特殊客人与普通客人卡片式浏览，可按类型筛选；点击卡片查看完整详情。全站不显示"本篇/DLC"版本字样，类型显示已去版本前缀。
  - 营业图鉴·备菜表页：备菜料理按客人筛选，点表头排序，客人名可点击跳转详情；菜品均显示“Lv 1 / Lv 2 / …”等级。
  - 客人详情的前期/后期推荐菜谱、推荐明细表，以及“菜谱速查”页都会显示菜品等级（Lv 格式）。
  - 标签 chip 筛选：酒水速查、酒水推荐、菜谱速查、食材速查、推荐菜谱、加料排序的搜索框都支持“输入标签/拼音 → 回车固定为 chip”；多个 chip 同时满足（AND），也可以直接点击下方推荐标签，按 Backspace 删除最后一个 chip。例如酒水页依次输入 `wujiu` 回车、`kejiabing` 回车，即可同时筛选“无酒精”和“可加冰”。
  - 拼音搜索：全局搜索和所有页面搜索框都支持全拼、首字母；多音字会生成备选读音；模糊音默认开启，范围仅为 `z/zh`、`c/ch`、`s/sh`。例如 `saojiu` 可搜到“烧酒”，`chongyou` 可搜到“重油”，`wjj` 可搜到“无酒精”。
  - 菜谱/食材/酒水：按类型筛选，支持排序和全文搜索。
  - 加料参考（备菜表页）：把各客人的加料建议拆成“客人 / 场景 / 适用推荐菜 / 食材 / 价格 / 等级 / 标签 / 补足标签 / 获取方式”，默认按食材价格从低到高，可点表头或下拉框切换价格/等级升降序，也可按客人和场景筛选。
  - 推荐酒水（备菜表页）：把各客人的推荐酒水拆成“客人 / 酒水 / 价格 / 等级 / 标签 / 命中喜好”，默认价格从高到低，可切换价格/等级升降序、匹配喜好优先/从少到多，也可按客人筛选。
  - 客人详情里“推荐酒水”放在“推荐菜谱”前面，并默认按价格从高到低显示，可切换排序；加料推荐同样展示按价格排序的食材表，并保留原始建议文字。
  - 攻略对照：保留 B 站 2024 / 2021 攻略原文，方便和最新数据对照。
- 数据每张表都内嵌在 HTML 中，与 Excel 成品同源；原版数据生成入口为 `py 脚本/build_html.py`。料亭版使用固定的原 JSON / 基线快照，数据升级需先核对新来源并同步基线；界面构建不会自动重算推荐或覆盖原版。
- 界面默认深色，右上角可切换浅色；支持手机/平板浏览，表格区域可横向滚动。
- 界面与动效（2026-10-05 升级）：夜色灯笼光晕与萤火粒子背景、页头渐变标题、tab 行整体居中（窄屏自动退回左对齐可滚动）且底部有滑动指示器、
  客人卡片级联入场与鼠标聚光悬停、按钮涟漪、详情侧栏弹性滑入与分区级联、表格斑马纹/行指示条/

## 统计口径

- 菜品标签按夜雀助手 `FoodCatalog` 口径：单价 >60 补“昂贵”，单价 <20 补“实惠”；
  肉覆盖素、重油覆盖清淡、饱腹覆盖下酒、灼热覆盖凉爽、大份覆盖小巧。
- 游戏积分：每命中一个喜好标签 +1，命中一个厌恶标签 -1；“拿手标签”另列。
- 流行喜爱/厌恶随每日剪报变化，静态列出但不计入固定评分。
- 前期：本体 DLC0、菜谱等级 ≤3、单价 ≤120、材料本体早期可获取、来源关卡/羁绊 ≤3；
  优先喜好命中 ≥2 且无厌恶。后期：价格不超过持有金上限，命中喜好/拿手 ≥3，优先高收益。
  该分级为查询规则，不是官方分级。
- 加料：优先命中客人喜好、且不与客人厌恶标签或菜品冲突标签冲突的食材；
  已排除特殊彩蛋食材“铃仙”（价格 530000）及 Mod 食材。
- 普通客人只有喜好标签、无厌恶和固定持有金；推荐价格上限为经验值（前期 ≤80、后期 ≤200）。
