# 集中配餐功能归档（2026-10-15 移除）

## 这是什么

2026-10-14“备菜与三步配餐产品改进”轮为攻略站实现的**集中配餐功能及其衍生功能**的完整源码与数据。
2026-10-15 用户决定整体删除该功能（“集中配餐功能，以及对应的衍生功能删除，但是不能影响到之前本就有的功能”），
已从活成品与构建管线中整体拆除。拆除时这些文件在 Git 中均为未跟踪状态，删除不可恢复，故按项目惯例移入本归档保留追溯；
如确定永久弃用，可整目录删除（删除前建议先取得用户确认）。

## 归档内容

| 文件 | 原位置 | 说明 |
| --- | --- | --- |
| `脚本/ryotei_meal_domain.js` | `脚本/` | 纯函数成餐、请求事实、预算与不可变就餐会话 |
| `脚本/ryotei_meal_ui.js` | `脚本/` | 三步配餐工作台、钱包账本、备菜清单、常用搭配存储 |

## 移除的功能范围

- 配餐工作台（“为此客人配餐”入口、选料理/选酒水/加料三步、换客人/新一桌）；
- 钱包与消费账本（余额快照、记一单已上餐、撤销、免费订单、预算批注）；
- “我的备菜清单”（自定份数、套餐、原料/酒水/厨具汇总、地区覆盖参考）；
- 常用搭配本机保存与 JSON 导入导出；
- 候选卡片、`pageKey` 分页复用与表格 `render` 列注入等仅供配餐使用的表格扩展。

## 保留未动的内容

之前已有的查询功能全部保留：图鉴/备菜表/物品图鉴、客人详情四页签、拼音与标签检索、
成餐标签自动重算（`meal_tags.py` 流水线）、加料页排序、详情分页/后退阅读恢复/手机布局修复、
立体头像效果块，以及配餐轮之前的一切数据、工作簿与旧成品。配餐轮的证据留在
`验证记录/2026-10-14--备菜与配餐产品改进/`，误投卡片 CSS 的撤回与更正记录保持有效。

移除过程的完整记录见 `记录/2026-10-15--集中配餐功能整体移除.md`。
