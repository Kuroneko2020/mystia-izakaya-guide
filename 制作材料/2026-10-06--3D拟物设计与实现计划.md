# 3D 拟物试验版 Implementation Plan

> **For agentic workers:** 使用原生内联实现，并按 requesting-code-review 做一次独立最终复核。非 Git 项目，以独立文件、输入快照和哈希隔离。

**Goal:** 单独制作原游戏像素夜摊风格的拟物查询页，保留最近成功的料亭版。当前取舍以用户同日后续反馈为准。

**Architecture:** 将成功成品作为只读、固定哈希的输入，保存不可变快照，只注入独立 CSS 与无交互装饰。原数据、资源、查询脚本和路由逐字保留，无新运行时脚本、无新依赖。

**Tech Stack:** Python 标准库构建、CSS perspective/transform/gradient/shadow、现有游戏像素资源、Node 检查、浏览器验证。

**Spec:** 本文的设计约束；用户 2026-10-06 指令“3d拟物风格”“尝试大改”“别覆盖最近的成功版本”，以及此前“你自己决定”、少说明文字、合理放大图标、避免刷新和点击阻挡。

## 设计与全局约束

- 官方像素夜景铺开，布帘页签、挂绳木牌、错落口味签、陶盘与游戏饭团/绿茶/蘑菇贴图。纸账册、皮质装订和黄铜商务页签已被用户否定。
- 只有装饰和悬停产生轻微透视，正文、标签、表格保持平直。图鉴头像随断点 74–91px，表内图标盒 42–46px（包含 2px 陶盘留边），详情料理盒 58–60px。
- 层次来自材质、接触阴影、亮边、纸边和按压状态；保留灯笼、萤火与悬停光，不加背景循环计算。
- 原料亭 HTML、构建脚本、模板、CSS、UI、导航、检查脚本、数据基线与工作簿不得改动。
- 输出到独立 `成品/东方夜雀食堂攻略查询_3D拟物试验版.html`；不得覆盖成功版。单文件离线，保留全部查询、地区、跨页与返回功能。
- 触屏取消卡片倾斜，窄屏隐藏装饰；减少动效模式禁止新增变形过渡。

## Review Focus

- 小屏主页面无横向溢出；宽表只在表内横向滚动。
