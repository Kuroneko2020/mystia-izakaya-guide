# 2026-10-05 HTML 界面美化与动效升级记录

## 目标与范围

用户反馈：`成品/东方夜雀食堂攻略查询.html` 功能正常，但 UI 不够优雅简洁、动效不够炫酷。
本次只改视觉与动效层，不改任何数据、查询逻辑和功能行为；改动源头是
`脚本/guide_template.html`（模板），改完用 `py 脚本/build_html.py` 重新生成成品 HTML。

## 关键改动（均在 脚本/guide_template.html）

### CSS（<style> 块全量重写，保留全部既有类名/结构）

- 页面底色移到 `html` 上，新增三层缓慢漂移的“灯笼光晕”氛围层（`.ambient`）与全屏萤火粒子画布（`#fx-canvas`，z-index:-1，不挡交互），再叠一层极低透明度的噪点纹理（body::after），提升质感。
- 统一设计令牌：新增 `--ease`、`--spring` 缓动变量与 `--serif` 字体变量；阴影、圆角、边框色微调。
- 标题（页头 h1、详情面板标题）使用琥珀色渐变文字；页头/页脚增加渐隐金线；品牌方块 hover 旋转发光。
- 卡片：hover 上浮 + 发光描边 + 鼠标跟随聚光（`--mx/--my` 径向渐变）；“查看详情 →”箭头 hover 平移。
- 表格：斑马纹、行 hover 左侧琥珀色指示条、排序列头高亮 + 动画箭头标记（`.sort-mark`）；短内容列自动不换行（≤8 字符的单元格加 `.nw`），修复“前期/本篇稀客”被挤成竖排的问题。
- 详情侧栏：spring 缓动滑入、背景模糊加深、分区（`.detail-section`）按序级联入场、小节标题圆点呼吸发光。
- 全局搜索下拉：毛玻璃 + `@starting-style` 弹出动画 + 活动项左侧光条。
- 工具栏 focus-within 光圈、计数徽章胶囊化、空状态装饰符号、涟漪（`.ripple`）等微交互。
- 新增 `@media (prefers-reduced-motion: reduce)` 全量降级：关动画、隐藏粒子画布。
- 移动端断点里 `.tabbar` 由 `position:static` 改为 `position:relative`（否则滑动指示器会锚定错位）。

### JS（新增“视觉动效”模块 + 少量渲染函数调整）

- `initFireflies()`：24 个萤火粒子，预渲染柔光贴图后逐帧 drawImage（避免每帧建径向渐变）；页面隐藏时暂停；亮色主题下自动降低不透明度。
- `initTabIndicator()`：tab 栏底部琥珀色滑动指示器（transform + width 过渡），切页/缩放/字体加载后自动对位；并挂 ResizeObserver 与 visibilitychange 兜底（修复视口变化后指示器滞留旧位置的问题）。
- tab 按钮行整体居中（用户追加需求）：11 个按钮包进 `.tab-row`（`margin:0 auto` 居中，窄屏溢出时自动退回左对齐并保持可滚动，避免 `justify-content:center` 在溢出时裁掉左侧按钮的问题）。
- `initSpotlight()`：事件委托监听 pointermove，给卡片写入 `--mx/--my`。
- `initRipple()`：tab/子 tab/图标按钮点击涟漪。
- `applyTheme()`：切换主题时挂 420ms 的 `theme-anim` 类做全局颜色柔化过渡，图标用 WAAPI 做旋转入场；首次初始化不触发过渡。
- `makeTable()`：排序标记由文本“▲/▼”改为带弹入动画的 `<span class="sort-mark">`，排序列头加 `.sorted` 高亮；≤8 字符的短单元格自动加 `.nw`。
- `guestCard()`、普通客人、4.4.0 新增、攻略对照、数据来源渲染：写入 `--i` 索引实现级联入场（延迟封顶 12 档）。
- **顺带修复**：`setPanelOpen()` 原来依赖 `requestAnimationFrame` 添加 `.open` 类；后台/被节流标签页里 rAF 不执行，会导致通过 hash 直达详情时面板看不见。改为强制回流（`void panel.offsetWidth`）后同步加类，前景动画不受影响；关闭收起定时器 230ms→400ms，匹配新的 0.38s 过渡时长。
