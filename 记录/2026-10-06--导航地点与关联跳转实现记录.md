本轮开始时 `成品/东方夜雀食堂攻略查询_和风版.html` 已不存在；本次没有删除、恢复或重建它。为保持料亭版可构建，从改动前料亭 HTML 的 `app-data` 逐字保存 `中间数据/料亭版攻略数据基线.json`，不是重新计算的数据。原 HTML 存在时仍优先读取，若与基线不一致则中止。原和风模板的本轮前后 SHA256 相同：`273628b0cb5dd78c79e81d6d3a8ca78c6293bce030da8ebb28fbc3fbe52e1632`。

营业地区的来源和证据边界沿用 `记录/2026-10-06--营业店面与来客机制调查.md` 及原数据中的出没地点：15 地区、59 位特殊/稀客、47 种普通客人。没有加入未经当前版本核实的逐店等级条件、自然来访百分比或概率排序。

## 实现

| 主入口 | 内部页面 |

| 客人图鉴 | 稀客与特殊客人 / 普通客人 |
| 配餐参考 | 料理 / 酒水 / 加料 |

11 个原 hash 页面保留，各主入口记住最近子页；页头版本号也可进入版本更新。

- 客人、普通客人和三种配餐页按“今晚开店”地区筛选；配餐可展开可能来访的头像名簿。料理、酒水、加料共享选中客人，地区变化后清理不再适用的客人选择。
- 客人、料理、主料、加料、酒水、获取地点、更新记录和旧攻略中的已知条目互相链接；旧攻略另有“查看当前图鉴”。无法对应现有条目的旧名称保留原文，不生成空目标链接。
- 链接参数携带地点和配餐客人；物品目标采用精确名称定位，清理冲突的版本、标签、食材类型和查询，展开对应详情。用户主动改变查询或标签后退出精确定位。
- 页面返回和浏览器后退/前进保存筛选、页码、页面滚动、表内纵横滚动、展开行/标签/攻略、来客概览以及人物详情阅读位置。页面切换立即定位内容区，避免平滑滚动造成等待。
- 继续保留原详情退场光效；关闭即释放背景点击，快速重开取消旧隐藏计时。同一条目重复 hashchange 不重新渲染背景列表。

主要改动：`脚本/guide_template_ryotei.html`、`ryotei_ui.js`、`ryotei.css`、`build_html_ryotei.py`、`verify_ryotei.cjs`；新增 `脚本/ryotei_navigation.js` 和数据基线。更新独立 HTML、构建校验、README、AGENTS；原始来源与工作簿未写入。构建同时刷新已有内嵌素材和 manifest，素材数量不变。

## 定位与修正的状态漏洞

独立只读审查和复测发现并修正：

1. 仅保存页面滚动会丢失独立表格的滚动及展开状态，改为保存相应阅读容器。
2. 同物品目标以 focus 名称判断“未变”，会漏清后来加入的阻挡标签，改为对显式目标检查并清理实际阻挡条件，同时保持路由幂等。
3. hero 和用户关闭详情绕过快照，分别统一导航和在关闭前保存详情快照。
4. 同页同筛选、不同页码时仅比较 state 会漏重绘，改为同时比较当前表的分页快照；无差异不重绘。
5. 首页空 hash 被当成无来源，改为保存可辨认的首页来源，实际后退仍返回原空 hash。
6. 旧攻略内容恢复年份但按钮高亮可能落后，控制同步时同时恢复年份高亮。

同目标标签阻挡和同页分页问题先加入失败回归再修正；其余补充对应状态验证，最终自动检查通过。只读审查未控制浏览器或编辑文件。

## 验证与证据

执行 `py 脚本/build_html_ryotei.py` 成功；随后 `node 脚本/verify_ryotei.cjs` PASS，覆盖逐字 JSON 一致性、离线资源、内嵌脚本语法、11 页保留、地区与共享客人、精确条目与幂等路由、阅读状态和年份恢复、同页分页、详情退场释放与快速重开。

本地浏览器实际观察：

- 三个主入口、子页与资料菜单的 11 页均可进入，所属主入口高亮正确，无控制台错误。
- 15 地区的稀客卡片数均与出没名单匹配；全部地区恢复 59 位 / 47 种。红魔馆 17 位 / 7 种，魔法森林普通客人 8 种；配餐红魔馆来客概览为 17 / 7。
- 红美铃选择跨料理、酒水、加料保留。配餐 → 炒肉丝 → 猪肉 → 返回菜谱 → 返回配餐，恢复地区和客人；冬酿进入酒水图鉴，单条定位并展开。
- 拼音 `fantuan` + Enter 定位饭团，清除旧 DLC5 / 肉筛选并展开；主动改标签后再打开同目标正常。
- 配餐第 2 页、表内 scrollTop=350，点菜品后返回恢复页码与 350。菜谱第 3 页 → 同页精确条目 → 清空查询到第 1 页 → 后退，实际恢复 101–150 / 163（第 3 页）。
- 2021 旧攻略 → 人物 → 2024 旧攻略 → 人物 → 连续后退，恢复 2021 高亮、25 条记录与原展开项。初次无 hash 首页的全局条目跳转有可用页面返回。

- 390×844、768×1024 和默认桌面 1056 宽均无整页横向溢出；表格在自己的滚动容器内。平板所观察的前五个配餐行高为 70px。
