# 2026-10-11：详情名字水印动态居中与随滚露底

## 目标与范围

用户反馈：名字长的客人（如"比那名居天子"6 字，字高约 764px 超出列表视口约 575px）水印底部字符被裁掉永远看不到；要求水印不必固定在顶部位置，动态居中；名字长到一页显示不下时，先显示上部分，往下滚动时跟随滚动露出名字底部，但到底后不再继续随内容走。

起点为 Git `16aec17`（工作区干净）。上一轮的"钉住不随滚"行为被本轮细化为两段式动态定位。

## 实现

伪元素改为真实元素才能测量与变换：

1. **`ryotei_ui.js`**：
   - `pane()` 在外层 `.detail-scroll` 内、`.detail-scroller` 之前插入 `<span class="detail-name-mark" aria-hidden="true">名字</span>`（独立类名避开模板旧 `.detail-watermark` 死代码样式的冲突），`data-name` 属性移除；
   - 新增 `ryoteiUpdateNameMark()`：测内层视口高 `h` 与名字高 `n`，装得下（`n<=h`）取 `min(h-n, max(10,(h-n)/2))` 垂直居中且与滚动无关；装不下取 `max(h-n, 10-scrollTop)`——顶部先露上段（10px 起），随滚动与内容同速上移，名字底缘到达视口底缘（shift=`h-n`）后钉住；
   - 触发点：`renderDetailPane` 渲染后同步调用一次 + `requestAnimationFrame` 再调一次（首次打开时渲染先于 `setPanelOpen` 解除 `#detail-panel` 的 hidden，同步测量因 `display:none` 被跳过，rAF 时面板已可测量——探针实测顶部 shift 读 0 定位缺失后补的修复）；内层 scroller 挂 passive scroll 监听；`ryoteiUiInit` 挂 window resize 与 `document.fonts.ready`（字体晚到改变名字高度时重算）。
2. **`ryotei.css`**：`.detail-scroll::before` 伪元素规则替换为 `.detail-name-mark` 元素规则（定位 `top:0`、`transform` 由 JS 写入；`writing-mode/字体/opacity .055/pointer-events:none` 等视觉不变，新增 `will-change:transform` 独立合成层）；≤620px 隐藏规则同步改名。
3. 超出视口的字形墨迹仍由外层 `overflow:hidden` 裁剪（上一轮机制），负 shift 时顶部多余字符、底部超出部分都被裁掉，不产生滚动溢出。

## 验证结果（活成品 2610112252）

- 探针（`脚本/调试/probe_detail_scrollbars.cjs` 已扩展水印状态采样）：
  - 长名"比那名居天子"（n=764 > h=575）：顶部 shift=10（露"比那名"上段），滚到底（scrollTop 3945）shift=-189=h-n（"名居天子"底段钉在视口底缘）——先上段、随滚露底、到底钉住 ✓；截图 `tab-meals.png`/`tab-meals-scrolled.png` 目检一致；
  - 短名"博丽灵梦"（n=509 ≤ h=609）：shift=50=(h-n)/2 居中，滚动前后不变（50→50）——居中固定 ✓；
  - 四页签横向溢出复查：外层 `overflowX:hidden` 用户不可滚、内层 sw=cw=897、羁绊页 sh=ch=420，前两轮结论未回归。
- `node 脚本/verify_ryotei.cjs` PASS；`node 脚本/verify_avatar_browser.cjs` PASS（15 地区、106 客人、分页、后退、桌面手机布局、零页面错误）。
- 修复时序 bug 过程中发现并保留在记录：2610112250 构建存在"首开顶部定位缺失（shift 未设），滚动后才纠正"的问题，rAF 修复后 2610112252 复测通过。
