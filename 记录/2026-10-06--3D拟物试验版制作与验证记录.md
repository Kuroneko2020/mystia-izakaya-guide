# 3D 拟物试验版制作与验证记录（2026-10-06）

## 交付与边界

用户要求另做 3D 拟物尝试，自行决定设计，不覆盖最近成功版本；继续保留游戏风格、
少说明文字、适当放大物品、紧凑信息呈现，以及无重复刷新和点击阻挡的查询路径。

独立成品为 `成品/东方夜雀食堂攻略查询_3D拟物试验版.html`。
当前是官方像素夜摊背景、挂绳木牌、布帘页签、错落口味签、突出纸面的原游戏头像、
陶盘料理图标和备菜静物。正文、标签、表格保持平直；空间层次用 CSS 透视、物体厚度、
投影和前后遮挡表达。没有新增运行时脚本、依赖或 WebGL 场景，不宣称是真正可旋转的 3D 模型。

成功料亭成品、原模板、数据基线、料亭构建/样式/导航及原始工作簿均未修改。
项目不是 Git 仓库；未初始化、未提交。新增文件和文档改动以本记录及构建清单追溯。

## 用户反馈与取舍

首轮实体纸账册、皮质装订、黄铜页签被用户指出像旧商务界面、平、普通、缺画面细节。
该尝试已停止，快照位于 `制作材料/3D拟物旧尝试/2026-10-06--纸账册/`；
`脚本/izakaya_3d.css` 不参与当前构建。验证目录内不带“夜摊_”前缀的截图属于这一首轮尝试。

随后曾生成写实微缩夜摊，用户进一步明确“别出现这种写实风格的图片”“背景可以直接用游戏资源”。
当前已移除生成图，恢复原官方像素夜景。生成图和提示仅作历史材料，见
`制作材料/3D场景素材/素材来源与生成提示.md`，不得误认为当前成品或已获视觉接受。

当前背景是既有 `脚本/ryotei_assets/night-stall.webp`，来自保存的 Steam 官方背景；
来源为 `原始资料/料亭版官方素材/sources.json`，人物及物品来源为
`脚本/ryotei_assets/manifest.json`。本轮没有再次联网取材、访问游戏目录或启动游戏。

## 文件与复现

- `脚本/build_html_3d.py`：读取固定成功 HTML，保存不可变输入快照，只注入独立 CSS、封面与无交互静物；写独立成品和校验 JSON。
- `脚本/izakaya_night_market.css`：当前夜摊皮肤、断点、主题、减少动态效果；旧纸账册 CSS 不再使用。
- `脚本/verify_3d.cjs`：保护成功输入、脚本逐字一致、源和内嵌 CSS/场景一致、离线资源；在内存中改回归读取入口，继承原料亭检查，不修改原检查脚本。
- `制作材料/3D拟物试验输入/料亭优化版_01d36ce39add.html`：字节一致的成功输入快照。
- 项目 `README.md`、`AGENTS.md`、设计与实现计划更新了当前入口、失败尝试和授权边界。

项目目录执行：

```powershell
$env:PYTHONIOENCODING='utf-8'
py 脚本/build_html_3d.py
node 脚本/verify_3d.cjs
```

输入料亭哈希变化会中止，不能自动覆盖或重建成功版。构建不调用旧入口 main()。
