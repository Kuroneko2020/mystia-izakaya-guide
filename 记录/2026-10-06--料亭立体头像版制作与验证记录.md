# 2026-10-06 料亭立体头像版制作与验证记录

## 目标与来源

用户希望把 `成品/东方夜雀食堂攻略查询_3D拟物试验版.html`（sha256 `837f7e85…`）客人图鉴页面的立体客人头像与悬停灵动效果搬到 `成品/东方夜雀食堂攻略查询_料亭优化版.html`（sha256 `01d36ce3…`）的客人图鉴页面，要求"稍微放大头像，做立体效果和动态"，且不得覆盖源文件。

用户过程中补充两点要求，均已落实：

1. **只要立体效果，不要拟物风**——不引入夜市皮肤、纸面纹理和硬 offset 贴纸阴影，阴影体系沿用料亭优化版原有的柔和暖色投影。
2. **头像位置适当下移**——首版头像带 `translateY(-8px)` 上浮显得顶卡片顶部，已取消基础态上浮并恢复原版居中对齐。

## 操作

- 新文件：`成品/东方夜雀食堂攻略查询_料亭立体头像版.html`（sha256 `162bdc90…`，2,521,232 字节）。两个源 HTML 与工作簿原样保留，哈希未变。
- 生成方式：Python 以二进制模式读取料亭优化版，在主 `</style>` 与 `</head>` 之间精确插入一段 3,182 字节的 `<style id="guest-avatar-3d">` 块（CRLF 行尾），插入前后做逐字节回插校验（新文件去掉插入块 == 源文件）。首次文本模式读写曾把全文件行尾 CRLF 转 LF，已废弃重做；最终产物与源文件仅差插入块本身。
- 未触碰任何构建脚本、模板与业务代码；未使用 `build_html_ryotei.py` 重新构建。

## 效果定义（新增 CSS 全部内容）

- 作用域仅 `#guest-grid`（稀客与特殊客人）与 `#normal-grid`（普通客人）两个客人图鉴页签；其余页面不受影响。
- 基础态：头像 54px→72px（≤1200px 76px、≤900px 84px、≤620px 90px），`perspective(500px) rotateY(-11deg) rotateZ(-4deg)`；每第 3n+2 张镜像 `rotateY(9deg) rotateZ(3deg)` 形成错落朝向；位置与原版对齐居中，不上顶卡边。
- 悬停：回正至 `rotateY(∓3deg) rotateZ(∓1deg)`、轻微上浮 6px、`scale(1.05)`，加深暖色投影并叠加 `0 0 16px #dca04f40` 微光；卡片自带的上浮与聚光灯保持原样，形成层次。
- 阴影：`0 9px 18px #65502a2b, 0 3px 7px #65502a24` 等柔和暖色投影，与料亭版既有风格一致；不使用试验版硬 offset 阴影。
- 无障碍与触屏：`@media(hover:none),(prefers-reduced-motion:reduce)` 下悬停动效回退为基础立体态。
- 对试验版的一处有意修正：试验版里第 3n+2 张头像因 CSS 特异性（0,4,0 > 0,3,0）悬停时完全冻结；本版为交错卡单独写了镜像方向的悬停规则，保证每张头像都有"灵动"响应。若要完全复刻试验版行为，删除该条规则即可。
